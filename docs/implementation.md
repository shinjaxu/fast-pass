# 快捷账户实现方案

用户已确认：Windows 10 绿色 EXE、主密码加密、托盘静默运行、Ctrl+P 显示/隐藏、账户维护、模糊查询和独立复制。

CSV 导入/导出：按 url,username,password,note 表头映射，忽略额外列；前三列任一为空或纯空白时跳过该行，note 可为空。有效记录一次追加并加密保存，显示导入和跳过数量；全部行被跳过时不保存。表头缺失或 CSV 格式错误仍整批失败。导出全部账户为 UTF-8 BOM CSV，保留原始字段内容及换行，包含明文密码。

## 技术与边界

C# / WinForms，使用 Windows 10 自带 .NET Framework，无第三方依赖。账户文件位于程序目录，主密码只参与派生密钥，不保存主密码。AES-256-CBC 加密，独立 HMAC-SHA256 密钥认证整个文件，PBKDF2-HMAC-SHA1 200000 次派生，随机盐和 IV。每次启动解锁一次，随后后台运行。忘记主密码无法恢复。

## 执行与验证

1. `src/Vault.cs`：账户模型、搜索、本地加密及原子保存；`tests/Tests.cs` 验证中文与特殊字符往返、错误密码、篡改、随机化、多次保存与搜索。
2. `src/Program.cs`、`src/MainForm.cs`、`src/Dialogs.cs`：启动解锁、托盘、全局快捷键、账户增删改、复制；验证窗口构造、真实热键注册、切换隐藏、编辑表单、剪贴板与数据落盘。
3. `build.ps1`：通过 Framework 编译器生成 `dist/FastAccount.exe`，支持 AnyCPU；运行全部测试并交付使用说明。

## 验收重点

- 密码、备注不进入日志；列表不展示明文密码。
- 写入失败不更新内存列表，不清空或覆盖无法解密的文件。
- 取消编辑不保存；删除必须确认；关闭窗口隐藏；托盘退出释放热键。
- 热键被占用应明确提示；重复启动不同时写同一数据文件。
- EXE 目录不可写时提示用户移动到可写目录。
